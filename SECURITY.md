# Security Policy

## Supported Versions

Only the latest release of **AsciiDocstring** receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in AsciiDocstring, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send an email or private message detailing the vulnerability, reproduction steps, and potential impact to the repository maintainer (`webmaven`).
3. We will acknowledge receipt of your report within 48 hours and work with you to remediate the issue promptly.
4. Security advisories and patch releases will be published on PyPI and GitHub Releases.
